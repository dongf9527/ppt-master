## 5. 问题分级

### P0（任务失败根因）

1. **双输入幻觉**。事后核伪：`projects/real/sources/` 下**既无 `公司模板.pptx` 也无 `需求.md`**，只有模型自建工作区与空 exports。源件大概率自造（冒烟已现形同行为），材料百分百自拟。工作流 §2 GATE 原文："a bare topic without facts is not enough — **ask for material**"。违反后直接后果：要求的 5 页中"数据页（用材料里的数字）"整个消失，实际输出按模板 6 页骨架填空。
2. **指令结构不服从**。要求 5 页（封面/背景 2 要点/方案 3 要点/数据/结尾），实际产出按模板 6 页逐页填，背景变 3 条、方案拆 3 页——模板骨架反客为主。
3. **备注机制幻觉**。全文检索同版本仓库：管线中**不存在** `<svg:data type="audio/remark">` 机制；真实机制是 `notes/<页名>.md` 文件（`svg_to_pptx` 的 discovery/builder 走 notesSlide XML）。模型嵌入 SVG 的 6 段备注**注定全部丢失**，且塞在 `</svg>` 之后的非法片段正是后续 XML 解析连锁崩溃的祸根。

### P1（过程失控）

4. **越权修改管线源码**：`template_structure.py`（+39 行 `_NSPACED_PREFIXES` 补丁，日志可见）与 `animation_config.py`（日志截断段之外，全文检索无痕迹）。
5. **非原子编辑自毁现场**：整文件重写产生重复嵌套 `<g>`、根元素闭合后续写内容；随后误诊为 namespace 未注册，绕查 BOM/lxml/ElementTree 源码。
6. **路线混杂**：在 Edit Native 工作区伪造 `spec_lock.md`（"Validated ✓"字样）、手工拼装 `svg_output/` 子目录、试错旗标组合；工作区命名 `company-template-workspace` 不符 `<stem>_pptx_to_svg` 规范，疑为手工拼装而非管线产物。

### 10.1 经过与关键证据

- **导入成功**：管线生成规范工作区 `demo_roundtrip_20261026`（符合 `projects/<slug>_<YYYYMMDD>` 约定），`slide_01.svg` 122 行就位，标题绿色 `#86BC25`、三 tspan 结构——真源件环节全程无幻觉。
- **Edit 做成了"追加"而非"替换"**：旧 `<text>` 未删、新 `<text>` 插入，双标题共存——

```xml
<text ... fill="#86BC25" ...><tspan x="59.98" dy="51.2">信息科技制度体系</tspan><tspan>建设</tspan><tspan>项目</tspan></text>
<text ... fill="#86BC25" ...><tspan x="59.98" dy="51.2">部署验收测试</tspan><tspan>建设</tspan><tspan>项目</tspan></text>
```

  新块本身携带正确全文（部署验收测试＋建设＋项目），错在旧块未删；照此导出首页将出现两行标题重叠。
- **上下文自耗**：此后每轮重复重读同样三个文件（slide_01.svg 122 行 / edit-native-pptx.md 176 行 / pptx_to_svg.py 245 行，单轮 ≈543 行源文本），约 32k 可用工作区 3 轮烧穿；CC 报 `Autocompact is thrashing: the context refilled to the limit within 3 turns of the previous compact, 3 times in a row`，终态 `0% until auto-compact · /model opus[1m]`，未到导出步骤。
- **环境杂音**：期间模型报告 Flask 缺失（原始日志未存档，待工作站核实属哪一环节；若为预览类辅助依赖，`pip install flask` 即可，与 roundtrip 导出主链路 python-pptx 无关，勿为此动 `skills/` 源码）。

### 10.3 问题定级

- **P1-① Edit 追加而非替换**：old_string 只锚住首个 tspan 文本，new_string 却塞入整个新 `<text>` 块——"替换"实际变成"插入"。**修复指令**（工作站复用）：删除旧 `<text>…</text>` 整块只留新块（新块标题内容已正确），或改用覆盖完整 `<text>` 元素的 old_string 做真替换；修完必走 `svg_quality_checker.py --roundtrip` 并开包验证主标题全文。
- **P1-② 上下文自耗（autocompact thrashing）**：9B 工作记忆不足致"读完就忘、再读循环"，单轮 ≈543 行 × 3 轮即烧穿。**这证明"一页一会话"只是必要条件而非充分条件——会话内还必须显式约束重读**。对照首战冒烟（任务 1，3m44s 闭环）：当时改动极小且未反复重读 workflow/脚本，第二轮在 Edit 失败后进入重读循环即失控。
- **P2-③ Flask 缺失待核实**（见 10.1 末条）。
